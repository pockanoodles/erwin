# Erwin V1 Cleanup Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Strip FluidCalendar surface cruft, fix the auto-scheduler deadline bug, and port the Mahoraga visual theme to Erwin.

**Architecture:** Six independent changes across routing, nav, branding, scheduling logic, config defaults, and CSS. Tasks 1–3 and 5–6 are purely cosmetic or config. Task 4 is the real bug fix: the scheduler currently ignores `dueDate` as a hard ceiling, placing tasks past their deadlines.

**Tech Stack:** Next.js 15 App Router, TypeScript, Prisma, Tailwind CSS + CSS variables (shadcn/ui pattern), NextAuth JWT middleware.

**Parallelization:** Split into 3 independent agent groups with no shared files:
- **Group A (Tasks 1–3):** routing + nav + branding
- **Group B (Task 4):** scheduler bug fix
- **Group C (Tasks 5–6):** default hours + theme
